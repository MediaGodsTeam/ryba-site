# Рыбный рейс — сайт заказов рыбы

Покупатель открывает сайт с телефона и видит, сколько заказов уже на каждой точке маршрута. Там же он видит таймер до конца приёма заказов. Заказ оформляется в три шага: точка, товары, имя и фамилия. После этого покупатель получает талон с номером и показывает его при получении.

Организаторы работают на странице `/admin` под паролем.

**Что видит покупатель:**
- где сейчас машина: «стоит на Мачуги 6», «едет на Бауцентр, около 11:30», задержка;
- сколько товара осталось на рейс; закончившийся товар заказать нельзя;
- окна по 15 минут внутри стоянки и сколько людей уже записано в каждое;
- примерную сумму заказа;
- талон с QR-кодом, сохранение талона в галерею, отмену заказа до начала стоянки;
- кнопку «Повторить прошлый заказ»;
- установку сайта на главный экран телефона как приложение.

**Что видят организаторы в `/admin`:**
- кнопки «Приехали» и «Уехали» на каждой точке и выбор задержки — покупатели сразу видят это на сайте;
- таблицу «Заказано / Везём / Свободно»: сюда вводится, сколько товара в машине;
- выдачу с взвешиванием: продавец вводит вес, сайт считает сумму, выручка видна по точкам и рейсу;
- переход по QR-коду: продавец наводит камеру телефона на QR в талоне покупателя, и заказ открывается сразу с полями для веса;
- отметку «не забрал N раз» у покупателей, которые раньше не забирали заказ;
- статистику: заказы, выдачи, неявки, отмены и выручку по неделям, а также рост и падение по каждой точке;
- поиск по номеру или фамилии и выгрузку таблицы для Excel.

Сервер ставится в России, поэтому для покупателей всё открывается без VPN. Сайт не загружает ничего со сторонних серверов: ни шрифтов, ни скриптов.

## Демо-версия на GitHub Pages

Чтобы посмотреть и потрогать сайт без сервера, в репозитории есть демо. После каждого изменения в ветке `main` оно публикуется само по адресу `https://ЛОГИН.github.io/ryba-site/`.

- В демо всё работает прямо в браузере: заказы, остатки, машина, выдача, статистика. Данные хранятся только у того, кто открыл страницу, и другим не видны. Для наглядности уже добавлены примерные заказы, а кнопка «Сбросить демо» возвращает всё к началу.
- Страница выдачи открывается по адресу `…/ryba-site/admin.html`, пароль `demo`.
- Чтобы демо включилось, один раз откройте в репозитории **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
- На настоящем сервере демо-режим не включается.

## Что внутри

| Файл | Что это |
|---|---|
| `server.js` | Сервер и база заказов. Нужен только Node.js 18 или новее, никаких библиотек ставить не нужно |
| `config.json` | Точки, время, товары, цены и время окончания приёма заказов. **Всё, что меняется от недели к неделе, правится здесь** |
| `public/` | Страницы сайта: для покупателей (`index.html`) и для выдачи (`admin.html`) |
| `data/orders.json` | Сами заказы. Файл создаётся автоматически при первом запуске |
| `data/state.json` | Где машина и сколько товара везём, отдельно для каждых выходных |
| `deploy/` | Готовые настройки для сервера |

## Запуск на российском сервере (около 30 минут)

### 1. Арендовать сервер
Подойдёт любой российский хостинг с VPS: Timeweb Cloud, Beget, Selectel, Яндекс Облако. Выберите:
- систему **Ubuntu 24.04**;
- **самый дешёвый тариф** (1 ядро, 1 ГБ памяти, этого хватит с запасом);
- **расположение в России**, например Москву или Санкт-Петербург.

После создания хостинг покажет IP-адрес сервера и пароль от пользователя `root`.

### 2. Купить домен
Купите домен `.ru` у регистратора (REG.RU, Timeweb, Beget). В настройках DNS добавьте **A-запись**: имя `@`, значение — IP вашего сервера. Добавьте такую же запись для `www`. DNS обновляется от нескольких минут до нескольких часов.

### 3. Загрузить файлы на сервер
Вариант А, через GitHub: создайте приватный репозиторий и загрузите в него эту папку. Файл `.gitignore` уже исключает базу заказов и пароли. Затем на сервере выполните:
```bash
git clone https://github.com/ВАШ_АККАУНТ/ryba-site.git /opt/ryba-site
```
Вариант Б, напрямую с компьютера:
```bash
scp ryba-site.zip root@IP_СЕРВЕРА:/opt/
ssh root@IP_СЕРВЕРА "cd /opt && apt install -y unzip && unzip ryba-site.zip"
```

### 4. Установить и запустить
Подключитесь к серверу командой `ssh root@IP_СЕРВЕРА` и выполните по очереди:
```bash
apt update && apt install -y nodejs caddy
node -v                     # должно быть v18 или выше

useradd --system --home /opt/ryba-site ryba
mkdir -p /opt/ryba-site/data && chown -R ryba:ryba /opt/ryba-site/data

# пароль для страницы выдачи: придумайте свой, не короче 8 символов
echo 'ADMIN_PASSWORD=придумайте-надёжный-пароль' > /etc/ryba.env
echo 'PORT=3000' >> /etc/ryba.env
chmod 600 /etc/ryba.env

cp /opt/ryba-site/deploy/ryba.service /etc/systemd/system/
systemctl daemon-reload && systemctl enable --now ryba
systemctl status ryba       # должно быть active (running)
```

### 5. Включить HTTPS
Откройте `/opt/ryba-site/deploy/Caddyfile` и замените `ryba-krd.ru` на свой домен. Затем выполните:
```bash
cp /opt/ryba-site/deploy/Caddyfile /etc/caddy/Caddyfile
systemctl reload caddy
```
Через минуту сайт откроется по адресу `https://ваш-домен.ru`, а страница выдачи — по адресу `https://ваш-домен.ru/admin`.

### 6. Проверить перед запуском
1. Оформите 2–3 тестовых заказа с разных телефонов.
2. Убедитесь, что счётчики на точках выросли. Страница обновляется сама каждые 20 секунд.
3. Зайдите в `/admin`, отметьте тестовый заказ выданным и удалите тестовые заказы.
4. Дайте ссылку покупателям: в Telegram-канале и QR-кодом на афише.

## Как работать на выходных

1. **До закрытия приёма заказов** откройте `/admin`, выберите рейс и заполните колонку «Везём» в таблице загрузки, затем нажмите «Сохранить». Пустое поле означает «без лимита». Когда свободный товар закончится, на сайте его нельзя будет заказать.
2. **На маршруте** на каждой точке нажимайте «Приехали», а при отъезде — «Уехали». Если опаздываете, выберите задержку вверху страницы: время на сайте для покупателей сдвинется само.
3. **При выдаче** наведите камеру телефона на QR-код в талоне покупателя: заказ откроется в `/admin`. Другой способ — найти заказ по номеру или фамилии. Введите вес весовых товаров и нажмите «Выдано». Сумма к оплате посчитается сама. Если взвешивать некогда, нажмите «Без взвешивания».
4. Чтобы QR-коды открывались сразу, один раз войдите в `/admin` на телефоне продавца в том же браузере, которым открываются ссылки из камеры. Вход сохраняется на 14 дней.

## Каждую неделю

- **Новые выходные открываются сами** в понедельник в 00:00 по Москве. Счётчики на сайте начинаются с нуля, а старые заказы остаются в базе и доступны в `/admin` через выбор выходных.
- **Приём заказов закрывается сам**. По умолчанию заказы на субботу принимаются до пятницы 21:00, на воскресенье — до субботы 21:00. Время меняется в `config.json`, поле `deadline` у каждого маршрута: `daysBeforeSaturday` — за сколько дней до субботы, `time` — во сколько. Кроме того, на точку нельзя заказать, когда машина с неё уже уехала.
- **Окна внутри стоянки** задаются в `config.json`, поле `slotMinutes` (по умолчанию 15 минут). Значение `0` отключает окна.
- **Цены для подсчёта суммы** задаются у каждого товара: `price` — цена, `per` — `"kg"` за килограмм или `"unit"` за штуку, `approxKg` — примерный вес одной штуки для оценки суммы на сайте.
- **Как поменять точки, время, товары или цены.** Отредактируйте `config.json`: точка записывается как `["Название", "Ориентир", "с", "до"]`. Затем перезапустите сервер командой `systemctl restart ryba`. Не меняйте `id` товаров и маршрутов посреди выходных, иначе уже оформленные заказы потеряют связь с ними.

## Резервная копия заказов

Чтобы каждый день сохранять копию базы, выполните один раз на сервере:
```bash
mkdir -p /opt/ryba-backup
( crontab -l 2>/dev/null; echo '0 3 * * * cp /opt/ryba-site/data/orders.json /opt/ryba-backup/orders-$(date +\%F).json' ) | crontab -
```

## Защита от спама и путаницы

- С одного подключения можно оформить не больше 40 заказов в час. Лимит выше обычного, потому что у мобильных операторов один адрес часто делят многие абоненты. Не больше 20 единиц одного товара в заказе — это настраивается в `config.json`, поле `maxPerItem`.
- В форме есть невидимое поле-ловушка для ботов.
- Отменить заказ может только тот, кто его оформил: у каждого заказа есть секретный ключ, который хранится только на телефоне покупателя.
- Номер заказа уникален в пределах выходных: буква маршрута, номер точки и три цифры, например `С2-502`. При выдаче ищите заказ по номеру или фамилии.
- Вход в `/admin` — по паролю, не больше 8 попыток за 10 минут. Пароль меняется в `/etc/ryba.env`, после этого выполните `systemctl restart ryba`.

## Персональные данные

Сайт собирает имя и фамилию. По закону это персональные данные, и на них распространяется 152-ФЗ: обычно нужны политика обработки персональных данных на сайте и уведомление в Роскомнадзор. Уточните требования у юриста или бухгалтера до запуска. Телефоны и адреса сайт не собирает, IP-адреса в базе не хранятся.
